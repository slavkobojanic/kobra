The language is called Kobra (the command stays `k`, and source files `.k`), and it is dual-licensed MIT OR Apache-2.0, with both licences in every release archive. Install it with `curl -fsSL https://slavkobojanic.github.io/kobra/install.sh | sh`, or `irm https://slavkobojanic.github.io/kobra/install.ps1 | iex` on Windows; until a stable release exists, the scripts install the newest release candidate and say so. The VS Code extension is `slavkobojanic.kobra`, and the toolchain image `ghcr.io/slavkobojanic/kobra`.
