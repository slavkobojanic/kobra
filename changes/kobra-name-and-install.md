The language is called Kobra (the command stays `k`, and source files `.k`), and it is dual-licensed MIT OR Apache-2.0, with both licences in every release archive. Until a stable release exists, the install scripts install the newest release candidate and say so. The VS Code extension is `slavkobojanic.kobra`, and the toolchain image `ghcr.io/slavkobojanic/kobra`.
