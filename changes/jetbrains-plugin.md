A Kobra plugin for JetBrains IDEs (IntelliJ IDEA, WebStorm, PyCharm and the others, 2026.2 or later, free versions included): `.k` highlighting from the VS Code extension's grammar and `k lsp` through the IDE's built-in language server support. Each release attaches it as `kobra-intellij-<version>.zip`, installed with Settings → Plugins → Install Plugin from Disk.
