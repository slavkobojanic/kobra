`editors/claude` is a Claude Code plugin with three skills (`kobra-language`, `kobra-apps` and `kobra-tooling`) that teach Claude to write idiomatic Kobra and to check it with the compiler. The plugin also starts the `k mcp` server, and installs with `/plugin marketplace add slavkobojanic/kobra` followed by `/plugin install kobra@kobra`.
