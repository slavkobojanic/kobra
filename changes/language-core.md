K, a statically typed language that compiles to JavaScript: structs, enums with payloads, classes and interfaces, generics with explicit type arguments and read-only covariance, units, typed errors with `throws`, `catch` by type and `catch unknown`, `async` functions and `Stream`s, and modules with visibility checked at compile time.
