`k mcp` is an MCP server for AI assistants (`claude mcp add kobra -- k mcp`): it serves the book, the design and compiler docs and the example apps built into `k`, plus the project it runs in, with tools to search and read them, explain a diagnostic code, and check Kobra code with the compiler.
