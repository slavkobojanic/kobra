The JetBrains plugin shows a file's previews in a **Kobra Preview** tool window beside the editor: it runs `k preview` for the project, follows the selected file and the cursor, updates as you type, opens on a preview from its **▶ Preview** hint, and has Grid and Open in Browser in its toolbar. A setting keeps it from opening by itself.
