# 8. Accounts

In this step you'll give Shelf accounts: people sign up with an email address and a password, sign in,
and each one sees only their own books. You'll store accounts in a table, start a session when someone
signs in, and guard the pages and the protocol so that only someone signed in reaches them.

Start from the project you finished in [step 7](07-routing.md), with `k dev` running. The finished step
is in the repository as `examples/learn/shelf/08-accounts`. Everything about accounts goes in a new
module, `src/accounts/`.

## Store the accounts

A signed-in person is known by an id, which K's `k.auth` module needs to know the type of. Declare it in
`src/accounts/AccountId.k`:

```k
// examples/learn/shelf/08-accounts/src/accounts/AccountId.k
import k.auth.AuthUserId
import k.crypto.Uuid

/// The id of an account, and of the person signed in.
public struct AccountId implements AuthUserId {
    /// The random id behind it.
    let value: Uuid
}
```

An app has exactly one type that `implements AuthUserId`. Using it instead of a bare `Uuid` means an
account's id can't be passed where a book's id is wanted. Then the table, in `src/accounts/Account.k`:

```k
// examples/learn/shelf/08-accounts/src/accounts/Account.k
import k.db.Id
import k.db.Unique

/// A person who can sign in and keep a shelf: one row of the `account`
/// table. The browser never sees it.
public entity Account {
    /// The primary key, and the id of the session's user once they sign in.
    @Id let id: AccountId

    /// The address they sign in with, in lower case. No two accounts share
    /// one.
    @Unique let email: String

    /// A hash of the password. The password itself is never stored.
    var passwordHash: String

    /// When the account was made.
    let createdAt: Date
}
```

`@Unique` makes the database refuse a second account with the same email, even when two people sign up
at the same moment. And its repository, `src/accounts/AccountRepository.k`:

```k
// examples/learn/shelf/08-accounts/src/accounts/AccountRepository.k
/// The `account` table, for the server's code.
public repository AccountRepository for Account {
    /// Returns the account with this email address, or `nil` when there is
    /// none.
    func byEmail(email: String) async -> Account? {
        return await accounts.first { account => account.email == email }
    }
}
```

Each book now belongs to an account. In `src/books/BookRecord.k`, add an owner after the id:

```k
// examples/learn/shelf/08-accounts/src/books/BookRecord.k
import accounts.AccountId

import k.db.Id

// ...

    /// before Shelf had accounts.
```

`@Index` makes finding an account's books fast. The field is optional because the table already has
rows, the books you added in earlier steps, and they have no owner. Without the `?`, `k check` says so:
a field added to a table with rows "needs a default value or an optional type". Those books stay in the
table, but no one sees them any more.

## Sign up and sign in

Both forms ask for the same two things, in `src/accounts/Credentials.k`:

```k
// examples/learn/shelf/08-accounts/src/accounts/Credentials.k
import k.text.EmailAddress
import k.validation.Length
import k.validation.Validatable

/// The email address and password someone signs up or signs in with.
public struct Credentials implements Codable, Validatable {
    /// Its type checks that it's an email address.
    var email: EmailAddress

    @Length(min: 8, message: "Use at least 8 characters")
    var password: String
}
```

An `EmailAddress` field needs no rule: text that isn't an email address doesn't parse, and the form says
so under the field. Each rpc gets an error of its own, in `src/accounts/SignUpError.k` and
`src/accounts/SignInError.k`:

```k
// examples/learn/shelf/08-accounts/src/accounts/SignUpError.k
import k.rpc.RpcFailure

/// Why making an account failed.
public enum SignUpError implements Error, Codable {
    /// Another account has this email address.
    case emailTaken

    /// The call didn't reach `AuthApi`.
    case rpcFailure(RpcFailure)
}
```

```k
// examples/learn/shelf/08-accounts/src/accounts/SignInError.k
import k.rpc.RpcFailure

/// Why signing in failed.
public enum SignInError implements Error, Codable {
    /// No account has this email address and password. Which of the two is
    /// wrong isn't said, on purpose.
    case invalidCredentials

    /// The call didn't reach `AuthApi`.
    case rpcFailure(RpcFailure)
}
```

The protocol, `src/accounts/AuthProtocol.k`:

```k
// examples/learn/shelf/08-accounts/src/accounts/AuthProtocol.k
import k.rpc.RpcOnlyError

/// What the browser can ask the server to do with accounts. Each call that
/// succeeds changes the session, and the browser's `Session` follows it.
public protocol AuthProtocol {
    /// Makes an account and signs it in.
    ///
    /// - Throws: `SignUpError.emailTaken` when the address is taken.
    rpc signUp(credentials: Credentials) throws SignUpError

    /// Signs an account in.
    ///
    /// - Throws: `SignInError.invalidCredentials` when the email address and
    ///   password don't match an account.
    rpc signIn(credentials: Credentials) throws SignInError

    /// Ends the session.
    rpc signOut() throws RpcOnlyError
}
```

A **session** is how the server remembers who's signed in between requests: the browser keeps a cookie
with a random id, and the server keeps the rest in its database. `SessionManager`, a server-only service
from `k.auth`, starts and ends sessions. Answer the protocol in `src/accounts/AuthApi.k`:

```k
// examples/learn/shelf/08-accounts/src/accounts/AuthApi.k
import k.auth.SessionManager
import k.crypto.Password
import k.crypto.Uuid
import k.rpc.RpcOnlyError
import k.time.Clock

/// The server's side of `AuthProtocol`.
public service AuthApi implements AuthProtocol {
    @Inject let accounts: AccountRepository
    @Inject let sessions: SessionManager
    @Inject let clock: Clock

    rpc signUp(credentials: Credentials) async throws SignUpError {
        let account = Account(
            id: AccountId(value: Uuid.random()),
            email: credentials.email.address.lowercased(),
            passwordHash: await Password.hash(password: credentials.password),
            createdAt: clock.now
        )

        do {
            try await accounts.insert(account)
        } catch .email {
            throw SignUpError.emailTaken
        }

        await sessions.signIn(userId: account.id)
    }

    rpc signIn(credentials: Credentials) async throws SignInError {
        let account = await accounts.byEmail(email: credentials.email.address.lowercased())

        // Check a hash even when there's no account, so the time the answer
        // takes doesn't tell which addresses have one.
        let hash = if let account { account.passwordHash } else { Password.unusableHash }
        let matches = await Password.verify(password: credentials.password, hash: hash)

        guard let account, matches else {
            throw SignInError.invalidCredentials
        }

        await sessions.signIn(userId: account.id)
    }

    rpc signOut() async throws RpcOnlyError {
        await sessions.signOut()
    }
}
```

- `Password.hash` turns the password into a slow, salted hash, and `Password.verify` checks a password
  against one. The password itself is never stored.
- `insert` throws when the `@Unique` email is taken; `catch .email` turns that into the rpc's own error.
- `sessions.signIn(userId:)` starts the session. The response sets the cookie.

The browser's service, `src/accounts/AuthService.k`, passes the calls on:

```k
// examples/learn/shelf/08-accounts/src/accounts/AuthService.k
import k.rpc.RpcOnlyError

/// The browser's way to sign up, in and out.
public service AuthService {
    @Inject let api: AuthProtocol

    /// Makes an account and signs it in.
    func signUp(credentials: Credentials) async throws SignUpError {
        try await api.signUp(credentials: credentials)
    }

    /// Signs an account in.
    func signIn(credentials: Credentials) async throws SignInError {
        try await api.signIn(credentials: credentials)
    }

    /// Signs out.
    func signOut() async throws RpcOnlyError {
        try await api.signOut()
    }
}
```

Now the two pages. `src/accounts/SignIn.k`:

```k
// examples/learn/shelf/08-accounts/src/accounts/SignIn.k
import k.ui.Router
import k.validation.Form
import k.validation.ValidationError

/// The sign-in page. A page that needs someone signed in sends everyone
/// else here, and `returnTo` takes them back afterwards.
public page SignIn {
    /// The page to go to after signing in.
    @Param let returnTo: Page = .home

    @Inject let auth: AuthService
    @Form var credentials: Credentials = .empty
    @State var problem: String? = nil

    func submit() async throws ValidationError {
        problem = nil

        do {
            try await auth.signIn(credentials: credentials.value)

            Router.navigate(to: returnTo)
        } catch .invalidCredentials {
            problem = "That email address and password don't match an account."
        } catch .rpcFailure(.invalid(let failure)) {
            throw failure
        } catch .rpcFailure {
            problem = "Couldn't sign in. Check your connection and try again."
        }
    }

    metadata {
        title("Sign in · Shelf")
    }

    view {
        main {
            heading(level: 1) { "Sign in" }

            form {
                textField(value: bind credentials.email)
                    .label("Email")

                passwordField(value: bind credentials.password)
                    .label("Password")

                if let problem {
                    paragraph { problem }
                        .role(.alert)
                }

                button { "Sign in" }
                    .type(.submit)
            }
            .class(.form)
            .on(submit: credentials.handle(submit))

            paragraph {
                "New to Shelf? "

                link(to: .signUp) { "Make an account" }
            }
        }
        .class(.page)
    }

    style {
        .page {
            maxWidth: 24rem;
            margin: 0 auto;
            padding: .lg;
            font: .body;
        }

        .form {
            display: grid;
            gap: .sm;
        }
    }
}
```

- `@Param let returnTo: Page = .home` has a default, so it's optional, and goes in the query string:
  `/sign-in?returnTo=%2Fbooks%2F…`. A parameter of type `Page` can only name a page of this app.
- `Router.navigate(to:)` moves to another page from code, as a link does when clicked.
- `submit` may throw a `ValidationError`: `.rpcFailure(.invalid(let failure))` is the server finding the
  form invalid, and `throw failure` hands it back to the form, which shows it under its fields.

## Guard the shelf

A **guard** is a check the server makes before it answers. `Authenticated`, from `k.auth`, refuses anyone
who isn't signed in. Guard the whole book protocol with `requires`, in `src/books/BookProtocol.k`:

```k
// examples/learn/shelf/08-accounts/src/books/BookProtocol.k
import k.auth.Authenticated
// ...
/// What the browser can ask the server to do with the books of the person
/// signed in. Only someone signed in may ask.
public protocol BookProtocol requires Authenticated {
// ...
```

Inside an rpc the guard covers, `session.user` is the person signed in, never `nil`. Every query in
`src/books/BookRepository.k` now takes the owner:

```k
// examples/learn/shelf/08-accounts/src/books/BookRepository.k
import accounts.AccountId
import k.crypto.Uuid

/// The `book_record` table, for the server's code. Every query takes the
/// owner, so no one reads another person's books.
public repository BookRepository for BookRecord {
    /// Returns every book on an account's shelf, the first one added first.
    func all(ownerId: AccountId) async -> List<BookRecord> {
        return await bookRecords
            .filter { record => record.ownerId == ownerId }
            .sortedBy { record => record.addedAt }
    }

    /// Returns the account's book with this id, or `nil` when it has none.
    func find(id: Uuid, ownerId: AccountId) async -> BookRecord? {
        return await bookRecords.first { record => record.id == id and record.ownerId == ownerId }
    }
}
```

`filter` keeps the rows its lambda accepts; like `first` and `sortedBy`, the compiler turns it into SQL.
In `src/books/BookApi.k`, inject the `Session` and pass `session.user.id` to every query, and to new books:


signing in you land on that book, because the redirect filled in `returnTo`.

## Check it

Every test starts signed out, and a guarded page shows nothing to someone signed out, so every test of
`Home` now fails. A test signs in with `SessionManager`, as `AuthApi` does, without making an account. In
`src/home/Home.test.k`, add the account and the line that signs in at the start of **every** test, and
pass the owner to `records.all`:

```k
    @Inject let sessions: SessionManager

        await sessions.signIn(userId: reader)
```

## Recap

In this step you:

- stored accounts with a unique email and a hashed password;
- started and ended sessions with `SessionManager`;
- guarded the protocol and the pages with `requires Authenticated`, and named the `@SignInPage`;
- read who's signed in with `session.user`, and kept each person's books their own;
- signed in from tests with `SessionManager`.
